# Flexus 生产部署与 1.0.0 发布实施计划

## 阶段一：生产静态托管

1. 为 `createApp` 增加可选的前端构建目录配置。
2. 先编写静态首页、SPA 子路径和 API 404 测试。
3. 实现 `express.static` 和非 API HTML 回退。
4. 验证开发模式不提供静态资源时仍可正常启动 API。
5. 运行服务端测试、类型检查和构建。

## 阶段二：容器化与持久化

1. 新增根目录 `Dockerfile`。
2. 新增 `.dockerignore`，排除密钥、数据库、依赖和非运行资产。
3. 使用 Node.js 24、冻结锁文件和 workspace 构建。
4. 设置 `/data/hotwords.sqlite` 持久化路径。
5. 容器启动前执行幂等种子初始化。
6. 若本机 Docker 可用，构建镜像并执行健康检查；否则完成静态审查并将云端构建列为部署步骤。

## 阶段三：README 与发布文档

1. 删除“前端尚未实现”等过时内容。
2. 补充作业、仓库、Figma、功能、架构和 AI 使用说明。
3. 补充开发、测试、构建和生产部署命令。
4. 说明数据来源、统计口径、外部服务限制和 SQLite 持久化。
5. 在线地址在真实部署完成后写入，不伪造 URL。

## 阶段四：本地发布验收

1. 执行 `pnpm test`。
2. 执行 `pnpm typecheck`。
3. 执行 `pnpm build`。
4. 以生产 Express 服务验证首页、子路径刷新、静态资源和 API。
5. 完成浏览器冒烟测试。
6. 分阶段提交实现和文档。

## 阶段五：华为云与远端发布

1. 用户确认购买 Flexus L 后创建实例。
2. 配置安全组、持久化目录和应用运行环境。
3. 部署版本镜像并完成公网验收。
4. 把公网地址和真实结果写入 README、博客。
5. 推送 `dev`。
6. 合并到 `main` 并再次验证。
7. 推送 `main`，创建 Release 1.0.0。
8. 记录最终提交历史、Release 与部署链接。

## 完成条件

- 本地与公网均能直接刷新 Vue 子路由；
- API 404 不返回前端 HTML；
- SQLite 在容器重启后保持数据；
- 测试、类型检查和构建通过；
- README、博客、仓库和 Release 信息一致；
- 远端 `dev`、`main` 与本地发布版本一致。
