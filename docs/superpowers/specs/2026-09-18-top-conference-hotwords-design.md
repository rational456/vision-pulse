# 顶会热词统计平台设计说明

日期：2026-09-18  
状态：已完成讨论，待用户复核  
对应作业：软件工程实践第二次作业——与 AI 结对编程（顶会热词统计）

## 1. 项目目标

开发一个面向计算机视觉论文的 Web 平台，以 CVPR、ICCV、ECCV 近年论文为主要数据源，支持论文获取和管理、热门研究方向分析、关键词图谱以及跨年份和跨会议的热度趋势动画。

本项目采用个人与 AI 结对的形式完成。设计与实现过程中需要保存关键提示词、AI 输出摘要、人工修改、采纳或拒绝理由以及调试过程，以满足作业对人机协作记录的要求。

## 2. 范围

### 2.1 基础功能

1. 论文信息获取
   - 支持输入单篇论文题目。
   - 支持批量导入 CSV 论文列表。
   - 获取并保存摘要、关键词、原文链接、会议和年份等信息。
2. 论文列表管理
   - 支持新增、编辑和删除。
   - 支持按题目精确查询。
   - 支持按编号、关键词、会议和年份进行模糊或组合查询。
   - 本地没有目标论文时调用 OpenAlex 查询内容，并在 DBLP 可用时校对书目信息；展示结果后由用户确认是否保存。
3. 热门方向分析
   - 根据筛选范围计算 Top 10 热门领域或研究方向。
4. 关键词图谱
   - 展示关键词热度及关键词之间的共现关系。
   - 点击关键词进入已应用对应筛选条件的论文列表。
5. 热度趋势动画
   - 比较不同年份、不同顶会的热词变化。
   - 支持播放、暂停和重新播放。

### 2.2 明确不做

- 用户注册、登录和权限系统。
- 收藏、评论和社交功能。
- 独立管理后台。
- Redis、消息队列、微服务等分布式基础设施。
- 将复杂机器学习模型作为基础功能依赖。

这些功能与本次基础评分项关系较弱，会增加开发、测试和部署风险。

### 3.1 前端

### 3.3 选型理由

开发者已有 Vue 3、TypeScript、Pinia、Express、REST API 和前后端联调经验。统一使用 TypeScript 可以降低上下文切换成本、共享数据类型，并将有限时间集中在基础功能、AI 协作记录、云端部署和博客展示上。

Spring Boot 与开发者的长期 Java 后端学习规划一致，但在当前时间范围内同时学习框架、数据库访问和部署会增加未完成基础功能的风险，因此不作为本次作业的主技术栈。

## 4. 总体架构

系统采用前后端分离开发、单服务生产部署的结构：

```text
浏览器
  │
  ├─ Vue 3 单页应用
  │   ├─ 热门方向总览
  │   ├─ 关键词图谱
  │   ├─ 热度趋势动画
  │   ├─ 论文列表管理
  │   └─ 论文导入与详情
  │
  ▼
Express REST API
  ├─ 论文增删改查
  ├─ 本地检索与外部数据源降级查询
  ├─ CSV 批量导入
  ├─ 关键词抽取
  ├─ Top 10 统计
  └─ 年份和会议趋势统计
  │
  ▼
SQLite
```

生产环境中，Vue 构建产物由 Express 作为静态资源提供，网页和 API 使用同一域名和端口，从而减少部署步骤并避免跨域配置。

## 5. 页面设计

### 5.1 首页／热门总览

- 展示论文总数、会议数和年份范围等统计卡片。
- 展示 Top 10 热门方向。
- 展示关键词图谱。
- 点击关键词跳转到带筛选条件的论文列表。

### 5.2 趋势分析页

- 选择会议、年份范围和统计指标。
- 通过动态柱状图展示年度热词排名变化。
- 通过折线图比较同一关键词在不同顶会中的热度。
- 支持播放、暂停和重新播放动画。

### 5.3 论文列表页

- 分页展示论文。
- 支持题目精确查询。
- 支持编号、关键词、会议和年份的模糊或组合查询。
- 支持新增、编辑和删除论文。
- 点击论文进入详情页。

### 5.4 论文获取／批量导入页

- 输入论文题目后优先查询本地数据库。
- 本地不存在时调用 OpenAlex，并在 DBLP 可用时合并书目信息。
- 展示外部检索结果，由用户确认是否保存。
- 支持 CSV 导入，并展示成功数、失败数和错误原因。

### 5.5 论文详情页

- 展示标题、会议、年份、摘要、关键词和原文链接。
- 根据关键词推荐相关论文。

### 5.6 关于平台页

- 介绍 CVPR、ICCV、ECCV。
- 说明数据来源、获取方式和使用范围。
- 说明关键词抽取和热度统计口径。

## 6. 数据策略

采用“预置数据集为主、OpenAlex 在线检索为辅、DBLP 可选校对”的方案：

1. 系统预先导入 CVPR、ICCV、ECCV 多年份论文数据，保证统计和图表稳定展示。
2. 用户查询本地不存在的论文时，调用 OpenAlex 获取摘要、主题和链接，同时尝试使用 DBLP 校对书目信息。
3. 外部查询结果不会自动写入数据库，必须由用户确认保存。
4. 任一外部数据源超时或异常时自动降级；仅在全部外部数据源不可用时返回明确错误，不影响本地数据和其他功能。
5. 博客中记录数据来源、获取方式和统计口径。

## 7. 数据模型

### 7.1 papers

| 字段 | 含义 |
|---|---|
| id | 内部主键 |
| externalId | 外部数据源编号，可为空 |
| title | 论文标题 |
| abstract | 摘要 |
| keywords | JSON 格式关键词数组 |
| conference | CVPR、ICCV 或 ECCV |
| year | 发表年份 |
| paperUrl | 原文链接 |
| source | 数据来源 |
| createdAt | 创建时间 |
| updatedAt | 更新时间 |

标题、会议和年份的组合用于辅助判断重复数据。外部编号存在时优先按外部编号去重。

### 7.2 keyword_stats

| 字段 | 含义 |
|---|---|
| keyword | 归一化关键词 |
| conference | 会议 |
| year | 年份 |
| count | 包含该关键词的论文数 |
| score | 热度占比 |
| updatedAt | 统计更新时间 |

`keyword + conference + year` 构成唯一统计维度。

### 7.3 import_tasks

| 字段 | 含义 |
|---|---|
| id | 导入任务编号 |
| fileName | 文件名 |
| totalCount | 总记录数 |
| successCount | 成功数 |
| failureCount | 失败数 |
| errors | JSON 格式失败原因摘要 |
| createdAt | 导入时间 |

## 8. 数据存储

项目中的数据分为三类：

- 运行数据：保存在 SQLite 数据库文件 `server/data/papers.db`，不提交 Git。
- 初始化数据：公开的 CSV 或 JSON 数据放在 `server/seeds/`，提交 Git。
- 数据库结构：建表及升级脚本放在 `server/migrations/`，提交 Git。

CodeArts 仅保存源代码、迁移脚本和允许公开的初始化数据。部署后实际数据库保存在华为云服务器持久化磁盘中。如果使用容器，数据库目录必须挂载持久化卷。

## 9. 后端模块

- `paper`：论文增删改查、分页、筛选和详情。
- `search`：本地检索与 OpenAlex/DBLP 降级检索。
- `import`：CSV 解析、校验、去重和批量导入。
- `analysis`：关键词提取、Top 10、共现图谱和趋势统计。
- `system`：健康检查、数据来源和统计口径。

模块之间通过明确的服务接口协作。路由只负责输入输出，业务规则放在服务层，数据库访问集中到数据访问层，避免在路由中直接编写统计或 SQL 逻辑。

## 10. 接口约定

统一响应格式：

```json
{
  "success": true,
  "data": {},
  "message": "操作成功"
}
```

```json
{
  "success": false,
  "error": {
    "code": "PAPER_NOT_FOUND",
    "message": "未找到对应论文",
    "details": null
  }
}
```

主要接口类别：

- `/api/papers`：列表、新增、编辑、删除和详情。
- `/api/search`：本地和外部数据源查询。
- `/api/imports`：CSV 导入及导入结果。
- `/api/analysis/top-keywords`：Top 10 热词。
- `/api/analysis/graph`：关键词共现图谱。
- `/api/analysis/trends`：跨年份、跨会议趋势。
- `/api/health`：服务健康检查。

接口的具体方法、参数和状态码在实现计划中定义。

## 11. 关键词提取和统计口径

### 11.1 关键词生成

1. 有原始关键词时优先使用原始关键词。
2. 没有关键词时，对标题和摘要进行英文分词。
3. 文本统一转成小写，去除标点、纯数字、停用词和过短词。
4. 保留常见技术短语，例如 `object detection` 和 `large language model`。
5. 对少量常见单复数和同义写法进行归一化。

### 11.2 热度计算

```text
热度 = 包含该关键词的论文数量 ÷ 当前会议与年份范围内的论文总数
```

同一篇论文中某个关键词出现多次仍只计一次。趋势页面同时提供论文数量和热度占比，避免因不同年份论文总量差异产生误导。

### 11.3 关键词图谱

- 节点表示关键词。
- 节点大小表示关键词热度。
- 连线表示两个关键词在同一篇论文中共同出现。
- 连线粗细表示共同出现次数。
- 默认限制节点数量和最低共现次数，防止图谱过密。

TF-IDF 或 TextRank 可作为后续扩展功能，不作为基础功能完成的前置条件。

## 12. 核心数据流

```text
预置数据或 CSV
    ↓
校验、清洗和去重
    ↓
写入 papers
    ↓
更新受影响会议和年份的 keyword_stats
    ↓
首页、图谱和趋势页面读取统计结果
```

```text
用户查询论文
    ↓
本地数据库
    ├─ 找到：返回结果
    └─ 未找到：查询 OpenAlex，并尝试 DBLP 校对
                    ↓
              展示候选结果
                    ↓
              用户确认后保存
```

## 13. 异常处理

- 单个外部数据源不可用：返回其余数据源结果和警告；全部不可用时提示外部数据源暂不可用，保留本地查询结果。
- 查询无结果：返回明确的空结果状态，不作为服务器错误。
- CSV 部分错误：采用部分成功策略，返回错误行号和原因。
- 重复论文：拒绝重复写入，并返回已有论文编号。
- 表单校验失败：在前后端同时校验必填项、年份和链接格式。
- 删除论文：前端二次确认；删除成功后更新相关统计。
- 图表无数据：展示空状态及调整筛选条件的提示。
- 未知后端错误：记录服务器日志，客户端仅接收安全的通用错误信息。

## 14. 测试策略

测试优先覆盖评分涉及的核心路径：

### 14.1 单元测试

- 英文分词、停用词过滤和关键词归一化。
- 热度占比和 Top 10 排序。
- 关键词共现次数计算。
- CSV 字段校验和重复判断。

### 14.2 API 测试

- 论文新增、读取、修改和删除。
- 精确查询、模糊查询和组合筛选。
- CSV 正常导入、部分失败和重复数据。
- OpenAlex/DBLP 无结果、超时和异常降级。
- 统计更新及趋势接口。

### 14.3 前端验收

- 点击关键词后正确跳转和筛选论文。
- 趋势动画可以播放、暂停和切换会议。
- 表单错误、加载状态、空状态和删除确认正常显示。
- 生产构建后的页面路由可以刷新访问。

测试工具采用 Vitest 和 Supertest。端到端流程以人工验收为主，并保留截图、GIF 或视频作为博客材料。

## 15. 部署设计

1. Vue 构建为静态文件。
2. Express 提供静态文件和 `/api` 接口。
3. SQLite 数据库保存在华为云服务器持久化目录。
4. 端口、数据库路径和外部 API 地址通过环境变量配置。
5. `.env`、数据库文件和运行日志不提交 CodeArts。
6. 提供初始化数据库及导入种子数据的命令。
7. 部署完成后验证首页、API、刷新路由、数据库写入及重启后的数据持久性。
